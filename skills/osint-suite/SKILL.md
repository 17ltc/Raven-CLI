# OSINT Suite

This is the consolidated entry point for Raven's OSINT skills. Work from lawful public sources, minimize personal data, and never turn research into unauthorized access, targeting, or exploitation.

## Workflow

1. Define the question, scope, date window, and collection limits.
2. Start with passive sources and preserve URLs, timestamps, hashes, and search terms.
3. Cross-check important claims with independent sources and grade source reliability and information credibility.
4. Correlate domains, IPs, certificates, social identities, IOCs, leaks, imagery, and timelines only when the linkage is evidence-based.
5. Separate observation, inference, and unresolved alternatives.
6. Produce a reproducible report with collection notes, limitations, privacy handling, and confidence.

Communication rule: do not mention confidence, reliability, Admiralty grades, or
source-quality labels for greetings, casual questions, or non-investigative
requests. Use those fields only when the user explicitly requests OSINT,
research, verification, attribution, or an uncertainty assessment.

## Included modules

The triage, domain, IP, certificate, digital-footprint, social, geolocation,
threat-intelligence, reporting, source-validation, privacy, phishing, attack
surface, IOC, passive-web, metadata, DNS, and URL workflows are consolidated
in this skill and exposed through Raven's OSINT tools.
