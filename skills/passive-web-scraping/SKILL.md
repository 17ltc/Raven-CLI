# Passive Web Extraction

Check `web_robots` before following a site's sitemap or links. Use one page at
a time, keep limits low, identify Raven honestly, and preserve URLs and hashes
when evidence matters. Never submit forms, evade rate limits, scrape private
areas, or build a broad index without explicit ownership and written scope.
