# DevOps

- Inspect the current build, package, deployment, and environment conventions before introducing tooling.
- Keep builds reproducible, configuration externalized, credentials out of source control, and logs actionable.
- Pin or constrain dependencies appropriately and cache only safe, deterministic artifacts.
- Add health checks, failure visibility, least-privilege permissions, and rollback guidance where applicable.
- Validate locally with the same commands and environment assumptions used by CI.
