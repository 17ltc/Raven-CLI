# Database

- Inspect the schema, migrations, indexes, constraints, transaction model, and access mode before writing queries.
- Use parameterized queries and explicit transactions for mutations.
- Treat destructive or irreversible changes as requiring confirmation and a rollback or backup plan.
- Check query plans and indexing when performance matters; avoid selecting unused data.
- Add migration and integration coverage for schema changes.
