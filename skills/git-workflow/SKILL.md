# Git Workflow

- Inspect status and the relevant diff before changing tracked files.
- Preserve unrelated user changes and never use destructive reset or checkout commands without explicit authorization.
- Keep commits focused, descriptive, and easy to review; do not include secrets or generated artifacts accidentally.
- Resolve conflicts by understanding both sides, then inspect the final diff and run relevant checks.
- Use history to understand intent when behavior or ownership is unclear.
