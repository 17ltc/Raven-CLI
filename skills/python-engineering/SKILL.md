# Python Engineering

Use this skill for Python features, services, libraries, and architecture changes.

- Inspect the existing package layout, entry points, dependencies, and tests first.
- Prefer small typed functions, explicit interfaces, standard-library solutions, and the project's current conventions.
- Preserve public APIs unless a migration is requested; handle errors at meaningful boundaries with actionable messages.
- Add focused tests for new behavior and run the narrowest relevant test command.
- Keep I/O, configuration, domain logic, and presentation separate.
