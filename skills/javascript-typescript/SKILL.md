# JavaScript and TypeScript

- Read package scripts, tsconfig, lint rules, and existing module conventions before editing.
- Prefer TypeScript types at boundaries, narrow unions, async/await, and small composable modules.
- Preserve runtime compatibility and avoid adding dependencies when the platform or current stack is sufficient.
- Validate changes with the project's typecheck, lint, and focused tests.
- Treat user input, filesystem paths, network responses, and serialized data as untrusted.
